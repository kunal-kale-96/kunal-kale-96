A deep learning project that classifies chest X-ray images into pneumonia-infected and normal cases.

- Used the **DenseNet architecture** and a dataset of 8,500+ labelled X-ray images.
- Applied data augmentation to support model generalization.
- Used **Grad-CAM** to create heatmaps highlighting image regions influencing predictions.
- **Technologies:** Python, TensorFlow, DenseNet, NumPy, Matplotlib, Grad-CAM.
